# Устройство BATCAVE

React + TypeScript + Vite. Весь сайт статический. Встроенная относительная база `./` и hash-навигация позволяют открывать его в подкаталоге репозитория GitHub Pages без серверных перенаправлений.

- `src/models.ts`: модель комикса, настройки, вычисление статистики.
- `src/data/catalog.ts`: только начальные метаданные. Инициализация базы выполняется один раз.
- `src/storage/db.ts`: IndexedDB через idb. Таблицы `comics`, `assets`, `config`.
- `src/storage/backup.ts`: валидируемые резервные копии, SHA-256, конфликты и атомарная транзакция восстановления.
- `src/reader/source.ts`: единый интерфейс страниц. PDF.js читает оригинальный Blob диапазонами 64 КБ; отключены автоматическая предварительная загрузка и streaming. PDF-ресурсы поставляются локально.
- `src/reader/image-size.ts`: проверка размеров PNG, JPEG и WebP до декодирования.
- `src/reader/Reader.tsx`: жесты, масштаб, сохранение страницы, вертикальное окно до пяти холстов.
- `src/components`: библиотека, редактирование, импорт, настройки, интерфейсные элементы.
- `scripts/service-worker.mjs`: после сборки составляет список всех необходимых статических ресурсов. Каждый релиз имеет отдельный cache. Активация обновления выполняется по кнопке.
- `tests`: unit-тесты, браузерные сценарии, собственные тестовые файлы.

Файл сохраняется как оригинальный Blob. CBZ читается через центральный каталог ZIP; извлекаются только нужные страницы. Нет массива всех распакованных страниц или PDF-изображений. JPEG/PNG/WebP декодируются по одной странице; вывод ограничен 4 млн пикселей на холст. URL обложек освобождаются при размонтировании карточек. Рендеры отменяются, холсты очищаются, ZIP и PDF worker закрываются при выходе.

Читалка отдельно хранит позицию и список реально открытых страниц. Переход ползунком на последнюю страницу не засчитывает все предыдущие. Статус «Прочитан» можно выставить независимо для бумажной книги; автоматически он выставляется после открытия всех страниц цифрового файла. Общая статистика объединённой бумаги группируется по `physicalGroup`.

Подсчёт времени — оценка видимой активности: тик раз в 5 секунд, пауза на скрытой вкладке, в настройках чтения и после 2 минут без действий. ОС может прервать приложение до последнего сохранения: возможна потеря нескольких последних секунд таймера.

SHA-256 вычисляется частями по 4 МБ. Дубликаты оригиналов обнаруживаются по полному SHA-256, а не имени или расширению. Резервный JSON не содержит бинарных вложений. Полный ZIP содержит `batcave.json` и `assets/<uuid>`. Перед транзакцией восстановления проверяются схема, ссылки на вложения, размеры, CRC ZIP и SHA-256. При совпадении ID или файла по умолчанию остаётся локальная запись; недостающий оригинал может быть возвращён из полной копии. По желанию совпадающие записи заменяются. Несовпадающие записи остаются.

Данные не отправляются на сервер. В опубликованной сборке нет аккаунтов, API-ключей, аналитики или CDN. Сеть используется при загрузке сайта и обновлении его ресурсов. Шрифты — системные.
