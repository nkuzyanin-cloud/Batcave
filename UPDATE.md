# Установка BATCAVE 1.2 поверх 1.0

1. До обновления сохраните резервную копию в настройках текущего приложения.
2. Распакуйте этот ZIP. Загрузите его содержимое в корень существующего репозитория BATCAVE с заменой совпадающих файлов и сохранением структуры папок. Не загружайте сам ZIP и не создавайте вокруг файлов дополнительную папку.
3. Если Pages работает через GitHub Actions, дождитесь успешного workflow. Если публикация идёт из ветки main/root, готовые index.html, assets, icons, manifest и sw.js в этом архиве обновят сайт напрямую.
4. Откройте установленное приложение при подключённом интернете. В библиотеке нажмите «Обновить», когда появится предложение новой версии. Если предложение ещё не появилось, закройте и откройте приложение снова.
5. В настройках версия должна стать BATCAVE / 1.2.0. Сохраните тот же адрес сайта и существующую установку PWA, чтобы продолжить пользоваться её локальной базой.

Это архив обновления, не самостоятельная полная установка. В нём только новые и изменённые файлы относительно BATCAVE-1.0.zip. Старые assets можно оставить: открытая старая версия продолжит работать до обновления service worker. PDF worker и PDF-ресурсы повторно не включены.

Исходники обновляются в project/. Читалка сохранена. При первом запуске удаляются только достоверно нетронутые автоматически созданные стартовые записи. Импортированные и изменённые записи, оригиналы, фото, настройки и прогресс сохраняются. Подробнее — project/docs/REDESIGN.md.
